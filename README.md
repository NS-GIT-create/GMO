### Blocker-6（自動実行の決定的ブロック）

署名依頼にはPDFの実ファイルのアップロードが必須だが、本コンテナへPDFバイナリを配置する経路が
**全て塞がっている**（Drive MCPは応答返却のみ・認証済みDrive CLI不在・サービスアカウント鍵不在・
GoogleセッションCookie不在）。検証の全量は `docs/06_GMOサイン自動実行の可否検証.md`。

**認証情報ではなくPDF側がブロック箇所**のため、認証情報の展開は保留している
（236KBの全社認証情報台帳であり、到達点が変わらない状態で会話ログへ展開する合理性が無いため）。

解消は30秒：**契約書PDFを本ブランチへコミット**（GitHub Web UIからアップロード可）。
その後 `git pull` で取り込み、Drive正本の認証情報を参照してログイン試行へ進む。
