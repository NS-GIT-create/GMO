# GMOサイン送信準備｜AIシステム業務委託契約書（菊池様宛）

最終更新: 2026-09-07 15:17 JST / 更新者: Claude（NEXT STYLE 野村 依頼）

## 結論（先に）

**最終QAはPASSしていない。したがってHuman Gate（送信承認依頼）は上げない。**
GMOサインへの登録・相手情報設定・署名位置設定・外部送信は、本セッションからは**技術的に実行不能**。
理由は認証情報の欠如であり、契約条件に触れずに自己解決できる種類のエラーではない。

代わりに、**人手で3〜5分で送信完了できる状態**まで前工程を仕上げた。

| 工程 | 状態 |
|---|---|
| 1. 調査 | 完了 |
| 2. 前回メール復元 | 完了 |
| 3. 契約書特定 | 完了 |
| 4. 署名用PDF準備 | 部分完了（正本の所在特定まで。バイナリ取得は不能） |
| 5. GMOサイン登録 | **未実行（Blocker-1）** |
| 6. 相手情報設定 | **未実行（Blocker-1 + Blocker-3）** |
| 7. 署名位置設定 | **未実行（Blocker-1 + Blocker-2）** |
| 8. 最終QA | 実施済み・**FAIL**（下記） |
| 9. 送信 | **未実行**（QA未PASSのため承認依頼せず） |

## Blocker一覧

| ID | 内容 | 区分 | 解消者 |
|---|---|---|---|
| Blocker-1 | GMOサインの認証情報（ID/PW/APIキー）が本環境に存在しない。MCPコネクタも無し。ログイン不能 | 実行不能 | 野村様／松本様 |
| Blocker-2 | 契約書PDF（Gmail添付）のバイナリを取得する手段が本環境に無い。ページ数・署名欄位置を実物確認できない | 実行不能 | 野村様 |
| Blocker-3 | 菊池様のフルネーム・法人格・宛先氏名が未確定（判明しているのは `storeradar@storeradar.jp` のみ） | 要確認 | 野村様 |
| Blocker-4 | 菊池様からの「内容確認OK」返信が未受領（9/6送信→9/7時点で返信なし） | 要決裁 | 野村様 |
| Blocker-5 | 契約開始日 9/7 = 本日。署名完了は最短でも本日以降となり、開始日到来後の締結になる | 要決裁 | 野村様 |

## ドキュメント

- `docs/00_前回メール復元.md` — 復元した前回メール全文とメタデータ
- `docs/01_契約書特定.md` — 対象契約書の同定結果と契約条件
- `docs/02_GMOサイン送信仕様書.md` — GMOサイン画面へそのまま入力する値と手順
- `docs/03_最終QA結果.md` — QA判定（FAIL）と根拠
- `evidence/` — 送信後のEvidence保存先と記録テンプレート

## 次アクション（野村様）

1. **Blocker-4を決裁**：菊池様の確認返信を待つか、返信前に締結送信するか。
2. **Blocker-3を確定**：菊池様の氏名（漢字フルネーム）・法人名の有無。
3. `docs/02_GMOサイン送信仕様書.md` を開き、記載の値をGMOサイン画面に入力して送信（3〜5分）。
4. 送信後、`evidence/` のテンプレートに沿って証跡を保存。

Blocker-1が恒久的に解消可能なら、GMOサインAPI（契約印＆実印プラン＋API利用申込）の契約が必要。
現行プランは送信数制限あり（管理画面に「プランアップで送信数は無制限」表示）のため、送信枠残の確認も要。
