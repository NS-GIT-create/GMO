**準備完了に至っていない。理由：本環境から当該PDFのバイナリを取得する手段が無い。**

| 手段 | 可否 | 根拠 |
|---|---|---|
| Gmail MCP の添付ダウンロード | 不可 | 利用可能なGmailツールは `get_message` / `get_thread` のみ。添付は filename / id / mimeType のメタデータしか返らず、バイナリ取得APIが無い |
| Google Cloud アクセストークンでGmail API直叩き | 不可 | `CLOUDSDK_AUTH_ACCESS_TOKEN` は tokeninfo で `invalid_token`。Gmailスコープ以前に無効 |
| Drive経由 | 不可 | Drive上に当該PDFが存在しない（上記探索結果） |

- ページ数の確認
- 署名欄（甲欄・乙欄）の実座標特定 → **署名位置設定が不能**（Blocker-2）
- 契約書本文と前回メール記載条件の突合（終了日・稼働目安・報酬の税込表記など）

Gmailで当該メールを開き、添付PDFを **Drive `03_契約管理` へ保存**するだけで、
以降の内容突合・ページ数確認・署名位置指定は本セッションから実施可能になる。
